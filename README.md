# Gravity Garden
You are a tiny robot trapped inside a strange garden where gravity changes direction every few seconds.

## Play

Open [`code/index.html`](./code/index.html) in a modern browser. Use **A / D** or **← / →** to move, **Space** or **↑** to jump, and **R** to restart. Collect all five glowing seeds and reach the gate on the right while gravity shifts around the garden.
